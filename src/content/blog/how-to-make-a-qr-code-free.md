QR codes turn a printed poster, menu or business card into a tap-to-open link. Making one is free and takes seconds — and unlike some sites, you don't need to sign up or pay to keep it working.

## What you can put in a QR code

- **A website or landing page** — the most common use.
- **A menu or PDF** hosted online, so customers scan instead of touching a paper menu.
- **Contact details** so people can save your info in one tap.
- **A Wi-Fi network**, so guests connect without typing a password.

## Make one in three steps

1. **Open the [QR code generator](/tools/qr-code-generator).**
2. **Paste your link or text.** The code updates live as you type.
3. **Download a high-resolution PNG** — big enough for print without going blurry.

## Beware "free" QR sites that expire

Many QR generators create a *dynamic* code that routes through their server — and stop working when your trial ends or the company disappears. A **static** code (like the one PikFinder makes) encodes your link directly, so it works forever with no subscription. For anything printed, always use a static code.

## Put it on a real design

A bare QR code is easy to ignore. Add it to a flyer, poster or table card and it gets scanned far more often:

- Drop it onto a [flyer](/templates/free-flyer-templates) or [menu](/templates/free-menu-templates) template.
- Add a short prompt like "Scan for the menu" next to it.
- Design the whole thing in [Creator Studio](/studio) and export in HD.

## Tips for scannable codes

- Keep good contrast — dark code on a light background scans best.
- Don't shrink it too small; 2×2 cm is a safe minimum in print.
- Test it with your own phone before printing hundreds.
