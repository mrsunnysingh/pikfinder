Nothing ruins a great design faster than having key text cut off by a circular profile avatar, a mobile navigation bar, or compression artifacts from uploading the wrong canvas size.

Platforms update their UI layouts frequently. Here is the verified dimension and aspect ratio guide for social media imagery in 2026.

## 1. Instagram Dimensions

- **Feed Square Post:** 1080 x 1080 px (1:1 aspect ratio)
- **Feed Portrait Post:** 1080 x 1350 px (4:5 aspect ratio) — *Recommended for maximum screen real estate on mobile feeds.*
- **Feed Landscape Post:** 1080 x 566 px (1.91:1 aspect ratio)
- **Stories & Reels:** 1080 x 1920 px (9:16 aspect ratio)
- **Profile Picture:** 320 x 320 px (displays as a circle)

### Pro Tip for Instagram Stories
Keep your text, stickers, and key subject details inside the center **1080 x 1420 px** vertical zone. The top 250 px and bottom 250 px are frequently obscured by profile handles, share buttons, and reply fields.

## 2. YouTube Dimensions

- **Channel Banner (Header):** 2560 x 1440 px (16:9 aspect ratio)
  - *Safe Zone for all devices (Mobile & Desktop):* **1546 x 423 px** in the dead center.
- **Video Thumbnail:** 1280 x 720 px (16:9 aspect ratio, minimum width 640 px, max file size 2 MB).
- **Channel Profile Picture:** 800 x 800 px.

## 3. LinkedIn Dimensions

- **Personal Profile Banner:** 1584 x 396 px (4:1 aspect ratio)
- **Company Page Cover:** 1128 x 191 px
- **Feed Post Single Image:** 1200 x 627 px (landscape) or 1080 x 1080 px (square)
- **Document / Carousel Post:** 1080 x 1350 px (portrait PDF slides get higher engagement)

## 4. X (formerly Twitter) Dimensions

- **Header / Banner:** 1500 x 500 px (3:1 aspect ratio)
  - Leave bottom-left breathing room for your profile avatar on desktop.
- **In-Stream Single Image:** 1600 x 900 px (16:9) or 1080 x 1080 px (1:1)
- **Profile Photo:** 400 x 400 px

## 5. Pinterest Dimensions

- **Standard Pin:** 1000 x 1500 px (2:3 aspect ratio) — *Optimal for search feeds.*
- **Square Pin:** 1000 x 1000 px (1:1)
- **Long Pin:** 1000 x 2100 px (1:2.1)

## Exporting for Maximum Sharpness

When exporting from your editor:
1. Always design at 2x resolution if you plan to export text-heavy graphics.
2. Use PNG for crisp graphics with typography, or high-quality WebP/JPG (85-90% quality) for photos to prevent platform re-compression.
3. Test how your graphic appears on a mobile screen before posting.
